# Proyecto 1: Simulación de Planta de Motor CD

El script "proyecto1" se encuentra en la carpeta "script".

## Instrucciones
1. Al abrir el script en MATLAB se debe ecribir "proyecto1" en la línea de comandos y presionar 'ENTER' o simplemente presionar el botón 'RUN' para ejecutarlo.

2. El script pide el valor de las variables uno por uno en la línea de comandos.
    - En este orden: J, Ra, b, Kt, Kb. (En la línea de comandos se especifica cual se coloca)
    - Luego de colocar cada valor se debe presionar 'ENTER'.

3. Se calcula y grafica automáticamente la respuesta de la planta según los valores colocados.
