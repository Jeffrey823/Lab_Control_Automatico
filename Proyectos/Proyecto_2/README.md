El script "proyecto2" se encuentra en la carpeta "script".

## Instrucciones
1. Al abrir el script en MATLAB se debe ecribir "proyecto2" en la línea de comandos y presionar 'ENTER' o simplemente presionar el botón 'RUN' para ejecutarlo.

2. El script solicita la ubicación de los ceros en la línea de comandos.
    - Se puede dejar en blanco y presionar [ENTER] si no hay ceros.
    - Se pueden colocar ceros con signo negativo o positivo.
    - Cada cero debe ir separado por un espacio (tecla [SPACE]).
    - Luego de colocar todos los ceros se debe presionar [ENTER].

3. El script solicita la ubicación de los polos en la línea de comandos.
    - Se debe ubicar una mayor cantidad de polos que ceros.    
    - Se pueden colocar polos con signo negativo o positivo.
    - Cada polo debe ir separado por un espacio (tecla [SPACE]).
    - Luego de colocar todos los polos se debe presionar [ENTER].

4. Automáticamente se muestra en la línea de comandos:
    - Tabla de Routh.
    - Condiciones de Estabilidad (Rangos de K estables).
    - Resultado de Estabilidad.
    - Gráfico del Lugar de las Raíces (Root Locus).
